# ReactJS with Firebase - Test Assignment  

## 📌 Overview  
This project is a **ReactJS application** built with **Material Design Framework** and integrates **Firebase Firestore** as the database. It includes a **project management interface** where users can:  

- View a **table of all projects**  
- See **project details in a modal**  
- **Add new projects**  

## 🚀 Features  
✅ Built with **ReactJS** and **Material UI**  
✅ Uses **Firestore** for real-time data storage  
✅ **Project management UI** with CRUD functionality  
✅ **Material Design Framework** for a sleek interface  
✅ **Date handling** using utilities like **Moment.js** or **Date-fns**  
✅ Deployment on Vercel
